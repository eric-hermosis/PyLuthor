The second phase of the compiler is the syntax analysis, organized around the **synatax** of the language to be compiled.

The syntax is specified by the **grammar**. A grammar has four components:

- A set if *terminal* symbols.
- A set of *nonterminal* symbols.
- A set of *productions* where each production consists of a nonterminal named head, an arrow and a sequence of terminals and nonterminals.
- A designation of a nonterminal as the *start*.

The **parser** uses the first component of the tokens to create a tree representation that portraits the grammatical structure of the token stream.

A grammar derives strings by beginning with the start symbol and repeatedly replacing a nonterminal by the body of a production for that nonterminal. The terminal strings that can be derived from the start symbol form the language
defined by the grammar.

Parsing is the problem of taking a string of terminals and figuring out how to derive it from the start symbol of the grammar, and if it cannot be derived from the start symbol of the grammar, then reporting syntax errors within the
string.
